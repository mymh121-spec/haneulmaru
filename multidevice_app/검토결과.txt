코드 재검토 (2026-10-10)
=======================

수정
- 잘못된 인식 엔진 이름, NaN/무한대 추적 설정, 잘못된 입력 옵션을 거부하도록 개선.
- 비어 있는 영상과 실시간 연결 중단 시 구체적인 안내 표시.
- 초기화 실패 뒤 영상 창 정리 과정에서 원래 오류를 가리지 않도록 수정.
- 외부 IMU 어댑터의 누락·잘못된 값은 무효 상태로 처리.
- UNKNOWN 관측도 추적 인터페이스에서 처리할 수 있도록 개선.
- Android IMU 값 및 학습 벡터 검증 보강.

확인
- Python 9개 파일 구문 확인.
- 기본 설정 수용, NaN/무한대/음수 추적 간격 거부.
- 기존 학습 벡터 4방향 분류, 오래된 센서 무효화.
- disabled 엔진은 실제 추론 성공으로 보고하지 않음.
- 중복 프레임 거부, 녹화 영상에는 현재 IMU를 붙이지 않음.
- 추가로 누락된 IMU 필드와 잘못된 센서값을 확인.

확인하지 못한 부분
- ClikaRT SDK·라이선스·모델이 없어 실제 ClikaRT/YOLO 추론 및 추적 성능은 미확인.
- Windows/S22 실기기 카메라·USB/BLE 통신은 이번 검토에서 실행하지 않음.
- Kotlin/JDK/Android 빌드 환경이 없어 Android 컴파일은 미확인.
- Android 소스는 연결 인터페이스와 처리 기반이며 완성 APK가 아님.
- S22 영상 송신 앱, CameraX/BLE 수명주기, Android 추적기·SDK 바인딩은 후속 작업.
- 영상 decode 시각과 IMU 수신 시각의 연결은 근사이며 촬영 노출 시각 동기화가 아님.
