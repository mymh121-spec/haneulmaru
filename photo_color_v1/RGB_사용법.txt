사진 색상 표식 → R / B / G

classify_rgb.py는 표식 영역의 실제 픽셀을 읽습니다.
빨강=R, 파랑=B, 초록=G, 기준에 맞지 않거나 불분명하면 UNKNOWN입니다.
원본(none) 300장은 일괄 처리에서 제외하고 표식 사진 900장만 처리합니다.
폴더 자체에는 원본과 기존 자료를 모두 보존했습니다.

이 폴더에서 실행:
  python3 -m pip install -r requirements.txt
  python3 classify_rgb.py --output rgb_results.csv

시험용 분할의 표식 사진 90장만 처리:
  python3 classify_rgb.py --split test --output rgb_test_results.csv

한 장만 처리 (문자 하나 출력):
  python3 classify_rgb.py --image images/test/photo_0271_red.jpg

새 사진은 표식 위치를 픽셀 단위로 지정:
  python3 classify_rgb.py --image /path/to/photo.jpg --bbox 100 80 24 24
  순서: 왼쪽 x, 위쪽 y, 가로 폭, 세로 높이
Windows에서는 python3 대신 python을 사용해도 됩니다.

다른 Python 코드에서 import:
  from classify_rgb import classify_image
  code = classify_image("photo.jpg", (100, 80, 24, 24))
Pillow Image를 이미 갖고 있으면 classify_marker(image, bbox)를 호출합니다.
여러 표식은 각 표식 bbox마다 따로 호출합니다.

처리 방식과 범위:
- manifest.json에서 파일 경로와 marker_bbox 좌표만 사용합니다.
- marker_color, marker_labels의 클래스 번호, 파일명의 red/blue/green은 정답으로 읽지 않습니다.
- 원형 표식 중앙의 픽셀 색조·채도·밝기로 판별합니다.
- 표식 위치가 이미 알려진 정지사진용 규칙입니다. 사진 전체에서 드론이나 표식 위치를
  자동 탐지하는 모델은 아닙니다. 새로운 사진에는 정확한 bbox가 필요합니다.
- 실물 표식의 조명/반사/가림에 대한 정확도를 측정한 결과는 없습니다.
- 이번 추가에서 학습이나 테스트를 실행하지 않았습니다. 기존 validation_report.json은
  기존 데이터셋 구조 검사 결과이며 이 색상 판별 코드의 정확도 보고서가 아닙니다.
- 결과 파일이 이미 있으면 덮어쓰지 않습니다. 다른 --output 이름을 지정하세요.
