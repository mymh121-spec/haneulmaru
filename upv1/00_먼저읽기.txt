하늘마루 — 팀원 전달 / NUCODE IMU 연결 준비

1. 이 폴더 전체를 다른 Windows PC로 복사하거나 ZIP을 풀어 주세요.
2. Python 3.10 이상이 설치된 PC에서 하늘마루_실행.cmd를 실행합니다.
   첫 실행은 로컬 .venv 생성 및 reportlab 설치 및 공식 cloudflared 다운로드에 인터넷이 필요합니다.
   Codex, CUDA, PyTorch, Node.js는 실행에 필요하지 않습니다.
3. 자동으로 열린 PC 렌더러를 화면에 유지합니다. 포트는 8792입니다.
4. 폰을 같은 Wi-Fi/노트북 핫스팟에 연결하고 PC 화면의 새 QR로 접속합니다.
5. 폰에서 'PC 연결 시작'. 카메라 AR / 가상환경 전환 가능합니다.
6. 종료할 때 서버 명령창에서 Ctrl+C. 다음 실행은 새 URL/QR을 사용합니다.

폴더 내용
- experiments/haneulmaru_pro : 현재 PC 송신/휴대폰 수신 소스 및 로컬 Three.js
- tools/cloudflared : 라이선스/버전/원본 체크섬. 실행 파일은 첫 실행 때 공식 배포본 다운로드
- IMU_참고 : 기존 프로젝트 펌웨어 참고본, 패킷 파서 발췌, 합성 예제
- 01_IMU_연결합의.txt : 팀원이 먼저 읽을 연결 형식과 미구현 범위
- 02_구조와검증.txt : 처리/통신 구조와 확인된 한계
- FILES_SHA256.json : 전달 파일 무결성 체크섬

현재 완료: PC 3D 렌더링 → WebRTC 영상 → 폰 수신 및 폰 조작 역전송.
현재 미완료: NUCODE USB/BLE 입력을 이 렌더러에 직접 연결하는 어댑터.
기존 보드 펌웨어를 자동 업로드하거나 기존 계정/환경설정을 변경하지 않습니다.
폴더명과 경로에 한글/공백이 있어도 실행 경로는 따옴표 처리합니다.

전송 '선명 1920'과 장면 '균형'으로 시작하세요.
최고 지형 품질과 최고 전송 화질은 다른 설정입니다.
Microsoft Basic Render Driver가 표시되면 RTX 렌더링이 아닙니다.
PC 탭을 최소화/배경으로 두면 브라우저가 프레임을 제한할 수 있습니다.
신호 연결만 HTTPS 터널을 사용하며 영상은 WebRTC 직접 연결입니다.
AP 격리/방화벽으로 직접 연결이 차단되면 같은 Wi-Fi여도 실패할 수 있습니다.

AWS는 아직 연결하지 않았습니다. 계정/키/현재 접속 토큰/개인 로그는 포함하지 않았습니다.
