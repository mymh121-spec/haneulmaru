성능 한계:
현재 Chrome 실제 WebGL 장치: ANGLE Microsoft Basic Render Driver / Direct3D11.
고품질 10초 앱 내 측정 평균 6.5 FPS, P95 프레임 간격 166.8ms 관측.
이는 소프트웨어 렌더링 측정이며 RTX 2080 Ti 성능을 검증한 결과가 아님.
브라우저 배경 탭에서 FPS 제한됨. 실물 Android FPS, 카메라 권한/영상, 회전 센서, WebXR hit-test 배치는 사용자 기기 검증 필요.

기능 범위:
각 기기 자체 GPU 렌더링. PC-GPU 원격 영상 스트리밍이나 PC/폰 설정 동기화는 포함하지 않음.
PWA 방식이며 네이티브 APK 아님. 사진 같은 실측 지형 대신 합성 지형/절차적 색상과 형태 사용.
우드락·나무막대·삼각대 외형 케이스 생성 안 함. 사용자 치수 16.5×7.5×1은 cm 가정, 기록만 함.
