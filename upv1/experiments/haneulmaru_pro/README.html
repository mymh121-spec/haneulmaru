하늘마루 PRO

독립적인 고품질 합성 지형 / 가상환경 · 카메라 AR · WebXR 공간 AR. 기존 phone_ar 파일과 8790 서버는 변경하지 않습니다.

시작

  1. 이 폴더의 START.cmd 실행. PC 주소는 http://127.0.0.1:8791 입니다.
  2. 앱의 ‘연결 · 장치 · 저장’을 열고 QR 또는 HTTPS 주소로 Android Chrome에서 접속합니다. 별도 연결 코드는 없습니다.
  3. 휴대폰은 균형 또는 절전, PC는 높음부터 테스트합니다. 실제 GPU 이름에 Basic Render / SwiftShader가 나오면 NVIDIA 렌더링이 아닙니다.
  4. Chrome 메뉴의 앱 설치 또는 홈 화면에 추가. 설치 메뉴 지원 여부는 브라우저에 따라 다릅니다. APK가 아닌 설치 가능한 웹앱(PWA)입니다.

모드와 조작

  • 가상환경: 드래그로 궤도 회전, 휠/두 손가락 핀치로 확대, 두 손가락 이동. 초기 지점으로 복귀.
  • 2D 지도: 같은 장면을 정사영으로 위에서 봅니다. 다시 누르면 3D로 복귀합니다.
  • 카메라 AR: 휴대폰 카메라 위에 동일한 3D 장면을 합성합니다. 터치 또는 회전 센서 시점이며 실제 위치 추적/환경 가림 처리는 없습니다.
  • 공간 AR: WebXR immersive-ar 및 hit-test 지원 Android 환경에서만 실행됩니다. 바닥에 원이 나타나면 탭하여 지형을 배치합니다. 지도 크기 0.5~3m는 가상 지도 전체 폭이며 지형의 실제 축척을 의미하지 않습니다. 초기 지점 버튼으로 재배치합니다. AR 종료 후 가상환경으로 복귀합니다.
  • 가로/세로: OS 자동 회전을 켜면 화면 비율에 맞춰 캔버스와 메뉴가 재배치됩니다. OS 회전 잠금을 앱에서 강제 해제하지 않습니다.
  • 카메라를 끄거나 가상환경으로 전환하면 카메라 트랙을 중지합니다. 영상은 서버로 업로드하지 않습니다.

그래픽 구현

Three.js WebGL2. 고품질은 320×320 분할 지형, 최고는 480×480 분할 지형, 절차적 프랙탈 높이·하천 계곡·색상/표면 무늬, PBR 계열 MeshStandardMaterial, ACES 톤 매핑, 방향광과 PCF 그림자, 수면 셰이더를 사용합니다. 반복 숲·바위·건물·최대 200개 합성 비행체는 InstancedMesh로 묶어 그립니다. 외부 사진측량/DEM 데이터를 사용하지 않은 합성 공간이며 실제 군용 좌표나 실제 비행체 탐지 기능은 없습니다.

GPU 및 통신 선택

PC는 PC의 WebGL 장치, 휴대폰은 휴대폰 GPU가 직접 렌더링합니다. 이 버전은 PC GPU 화면을 폰으로 스트리밍하거나 PC 설정을 폰에 동기화하지 않습니다. HTTP 영상 전송의 지연을 없애는 것이 선택 이유입니다. CUDA 연산도 사용하지 않습니다. Unreal Pixel Streaming은 별도 엔진 실행·시그널링·네트워크 구성이 필요한 다른 선택지입니다. 현재 버전은 즉각적인 모바일 시점 조작과 가상/AR 전환을 우선합니다.

품질과 성능

절전 / 균형 / 높음 / 최고 품질, 실시간 FPS·삼각형 수·드로콜·캔버스 해상도를 표시합니다. 10초 성능 측정 후 평균 FPS와 P95 프레임 간격을 JSON으로 저장합니다. 네트워크 지연이나 카메라 지연을 측정하는 기능이 아닙니다. 최고 옵션이 항상 가장 빠르지는 않습니다. RTX 연결만으로 Chrome이 RTX를 사용하는 것은 아닙니다.

앱 설치·오프라인

manifest와 service worker가 정적 파일 및 로컬 Three.js를 캐시합니다. 첫 온라인 로드 및 캐시 완료 후 같은 주소에서 가상환경을 오프라인 실행할 수 있습니다. 브라우저가 캐시를 삭제하면 재접속이 필요합니다. Cloudflare 임시 주소는 서버 재시작 때 바뀌므로 장기 배포 주소가 아닙니다. 공간 AR 지원과 ARCore 설치 여부는 실제 폰에서 확인해야 합니다. 네이티브 Android APK 서명/패키징은 포함하지 않습니다.
