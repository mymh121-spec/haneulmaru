wan_V1 경량 정리 내역 (2026-10-10)
=================================

원본: mymh121-spec/haneulmaru main, 7c81fe5
원본 전체 자료: wan_V1 폴더 옆의 wan_V1_original.zip
정리본: wan_V1 폴더와 wan_V1.zip

실행 폴더에서 분리한 것
- 학습 사진 images, 드론 labels, 표식 marker_labels, COCO annotations.
- 생성된 미리보기 JPEG/HTML/샘플 목록.
- +imu data의 디자인 이미지 및 중복 방향 학습 JSON.
- 완료된 1회성 GitHub 데이터 복원 workflow (.github).
위 자료는 원본 ZIP에 보존했다.

유지한 것
- 기존 3D 화면/휴대폰 WebRTC 송수신, 실행 파일, 필수 vendor와 라이선스.
- S22 + NU40 실행 코드와 USB 우선/BLE 유지, 학습된 상하좌우 모델.
- ClikaRT·YOLO·ByteTrack·BoT-SORT 연결 코드와 Android 확장 계약.
- YOLO 학습/추적, 색상 규칙, 좌표 코드, S22 제공 카메라 메타정보.
- 데이터 출처/manifest/기존 검증 기록, 향후 개발에 필요한 기존 테스트.
- 참고 펌웨어. 장치에는 새로 업로드하지 않았다.

실행 중 낭비 감소
- 화면만 표시할 때 불필요한 JSON 문자열 변환 생략.
- JSONL 파일 flush를 프레임 처리 중 기본 0.5초 간격으로 묶음.
  --flush-every-frame으로 기존 매 프레임 flush 선택 가능.
- ClikaRT 전처리 배열 버퍼 재사용 및 박스 복원 배열 처리.
- 기존 화면의 nu40_imu.py는 공통 수신 코드로 연결하는 호환 모듈.
- 기존 화면/추적기의 학습 모델 경로를 공통 assets로 수정.
- FILES_SHA256.json을 현재 파일만 포함하도록 새로 작성.

학습 자료가 다시 필요한 경우
wan_V1_original.zip을 wan_V1 폴더 옆에 두고 저장소 루트에서:
  python photo_color_v1/restore_training_data.py
  python photo_color_v1/prepare_yolo_rgb.py
기존 학습 파일이 있는 경우 덮어쓰지 않는다.
원본 ZIP 경로가 다르면 restore_training_data.py --archive로 지정한다.

확인 범위
파일 역할과 참조를 읽어 정리했다. 이번 변경에서 실행 테스트, 하드웨어
연결, SDK 추론, Android 빌드 및 성능 측정은 수행하지 않았다.
현재는 확장 기반이며 ClikaRT SDK/라이선스/학습 모델이 필요하다.
GitHub에는 이번 오프라인 정리 변경을 업로드하지 않았다.
