구조
PC Three.js/WebGL → canvas.captureStream → WebRTC 비디오 → 휴대폰.
휴대폰 터치/방향/설정 → RTCDataChannel → PC 카메라 및 합성 장면.
Python 표준 HTTP 서버는 정적 파일과 SDP/ICE 시그널링만 처리합니다.
AR은 폰 카메라 + PC의 녹색 배경 제거 합성입니다. 정밀 공간 앵커 AR은 아닙니다.
소스는 합성 지형/합성 비행체 시각화이며 실제 센서 탐지 또는 위치 복원은 아닙니다.

확인한 것
- 기존 PC Chrome 두 탭에서 영상/조작 전달.
- 1920×1038 및 2560×1384 수신(PC 브라우저 테스트).
- 전송 설정 및 통계 계산 Node 테스트 2개 통과.
- 사용자 휴대폰에서 기존 버전 영상 수신 확인. 이동 시 화질 저하 보고됨.

확인하지 못한 것
- 이번 전달본을 다른 PC에서 설치/실행하는 전체 과정.
- NUCODE 직접 입력 통합 및 실물 축 보정.
- 전송 개선 후 실제 휴대폰 이동 화질/지연 측정.
- RTX WebGL 사용: 원래 테스트 PC에서는 Microsoft Basic Render Driver 표시.
- 실제 폰 AR 회전/크로마키의 품질과 안정성.
