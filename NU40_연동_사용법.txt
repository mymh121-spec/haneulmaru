NU40 → S22 USB → PC Wi-Fi

1. ZIP 전체를 Windows PC에 풉니다. 센서만 시험하려면 NU40_수신.cmd를 실행합니다. Python과 학습된 영상 모델은 이 시험에 필요하지 않습니다.
2. 폰과 PC를 같은 공유기 또는 PC 모바일 핫스팟에 연결합니다. 양쪽이 통신할 수 있는 사설망에서 사용하고, Windows 개인 네트워크에서 수신기에 UDP 8793을 허용합니다.
3. S22에 Haneulmaru-USB.apk를 설치합니다. NU40의 USB 데이터 포트와 S22를 OTG 데이터 케이블로 연결합니다. 앱을 열고 PC Wi-Fi IPv4 주소, 포트 8793, PC 창의 Pair key를 입력합니다. USB → Wi-Fi 시작을 누른 뒤 USB 접근을 허용합니다.
4. PC 창에서 event=sample, source=USB/Wi-Fi, t_ms가 계속 바뀌는지 봅니다. NU40을 움직이면 direction에 up/down/left/right가 표시됩니다. USB를 뽑으면 전송이 멈추고 재연결하면 새 세션으로 수신합니다. 웹 화면과 영상 파이프라인은 350ms가 지난 입력을 무효 처리합니다. 폰의 전송 건수는 송신 건수이며 수신 확인은 PC에서 합니다.
5. 센서 시험을 마치면 PC에서 Ctrl+C를 누릅니다. 웹 데모(하늘마루_실행.cmd)와 영상 인식(multidevice_app)은 각각 같은 Rust 수신기를 시작합니다. 포트 8793을 동시에 쓰는 모드는 하나만 실행하고 모드 전환 시 새 PC 키를 폰에 입력합니다.

Android 앱은 NU40 USB VID 239a / PID 80da, CDC ACM 115200 8N1을 사용합니다. USB 접근이 거절되면 앱에서 시작을 다시 누르세요. 앱의 중지 버튼은 USB와 UDP 전송을 닫습니다. 공유기 없이 PC 핫스팟을 쓰면 PC의 핫스팟 인터페이스 IPv4 주소를 입력합니다. 127.0.0.1 및 0.0.0.0은 폰의 목적지 주소가 아닙니다.

폰은 줄 단위 USB JSON을 PC에 UDP로 전달하고 PC Rust가 입력 검증과 방향 판정을 합니다. 현재 보드 v1과 참고 펌웨어의 type=imu/schema=1 형식을 지원합니다. PC의 신규 실행마다 페어링 키가 바뀝니다. 패킷에는 키가 평문으로 실리므로 신뢰하는 사설망에서 사용하세요. 키와 순번이 일치하는 최신 샘플만 받습니다. USB 장착 축이 달라지면 학습 방향을 다시 보정해야 합니다.

영상 인식 실행 방법은 multidevice_app/구조와실행.txt에 있습니다.
